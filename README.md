# 🎙️ Настройка микрофона с помощью Equalizer APO

Здравствуйте! В этой инструкции я подробно расскажу, как создать собственную конфигурацию для микрофона с помощью **Equalizer APO** и VST-плагинов **ReaPlugs**.

Я вам помогу настроить базовые параметры микрофона, создать конфигурационный файл и добавить два VST-плагина: ReaGate и ReaComp.

Давайте приступим!

# ⚙️ Базовая настройка микрофона

Перед созданием конфигурации необходимо правильно настроить само устройство записи.

## 1. Настройка уровня громкости

1. Нажмите **ПКМ** по значку звука на панели задач Windows.
2. Выберите пункт **«Звуки»**.
3. Перейдите во вкладку **«Запись»**.
4. Найдите свой микрофон и выделите его.
5. Нажмите кнопку **«Свойства»**.
6. Перейдите во вкладку **«Уровни»**.
7. Установите громкость микрофона в пределах **60–80%**.
8. Нажмите **«ОК»**, чтобы сохранить изменения.

> [!TIP]
> Если на вашем микрофоне имеется физический регулятор уровня громкости, расположенный непосредственно на корпусе устройства, установите его на максимум. Это нужно, чтобы настроенные VST-плагины работали правильно.

## 2. Отключение монопольного режима

1. Откройте **«Свойства»** своего микрофона.
2. Перейдите во вкладку **«Дополнительно»**.
3. Найдите пункт **«Разрешить приложениям использовать устройство в монопольном режиме»**.
4. Снимите соответствующую галочку.
5. Нажмите **«Применить»**, чтобы сохранить изменения.

> [!IMPORTANT]
> Отключение монопольного режима помогает избежать ситуации, когда отдельное приложение получает исключительный доступ к микрофону. Это позволяет Equalizer APO обрабатывать аудиосигнал для последующего использования в приложениях, например Discord и Telegram.

# 🛠️ Создание конфигурации Equalizer APO

Теперь перейдём к созданию собственной конфигурации.

## 3. Создание конфигурационного файла

1. Откройте **Equalizer APO Configuration Editor**.

2. Нажмите на зелёную кнопку **«+»**.

3. Выберите **Control → Include (Include configuration file)**.

   **📷 Визуальный пример — меню добавления Include:**

   <img width="432" height="209" alt="image" src="https://github.com/user-attachments/assets/a2ec512c-5a18-42a5-af1c-ea64b8c30d54" />

4. Нажмите на значок голубой папки.

   <img width="327" height="54" alt="image" src="https://github.com/user-attachments/assets/5a6976d3-0b94-48cc-a5bc-9513ebb4cb04" />

6. В открывшемся окне выберите место для хранения конфигурации.

7. Нажмите ПКМ по пустому пространству и выберите **Создать → Текстовый документ**.

8. Назовите файл, например `Microphone`.

9. Выберите созданный файл и нажмите **«Открыть»**.

Теперь у вас есть отдельный конфигурационный файл, в котором можно хранить настройки.

# 🎚️ Настройка VST-плагинов ReaPlugs

Для обработки микрофонного сигнала мы будем использовать два VST-плагина:

- **ReaGate** — шумоподавление, предназначенное для подавления фонового шума, когда вы не говорите.
- **ReaComp** — компрессор, предназначенный для выравнивания динамики и управления громкостью аудиосигнала.

## 4. Добавление ReaGate

1. Нажмите зелёную кнопку **«+»**.

2. Выберите **Plugins → VST plugin**.

   **📷 Визуальный пример — добавление VST-плагина:**

   <img width="321" height="290" alt="image" src="https://github.com/user-attachments/assets/4afcb3c9-04b9-4459-a697-f2d4aec75471" />

3. Нажмите на значок голубой папки.

4. Найдите файл `reagate-standalone.dll`.

5. Выберите его и нажмите **«Открыть»**.

6. Откройте добавленный плагин ReaGate.

### Рекомендуемые настройки ReaGate

Установите параметры согласно приведённой ниже таблице:

| Параметр | Значение |
|:---|:---:|
| Pre-open | `0 ms` |
| Attack | `3 ms` |
| Hold | `60 ms` |
| Release | `100 ms` |
| Hysteresis | `+3.0 dB` |
| Lowpass | `13000 Hz` |
| Highpass | `80 Hz` |
| RMS size | `1` |
| Threshold | `-45.0 dB` |

**Визуальный пример настроек:**

<img width="518" height="407" alt="2  ReaGate" src="https://github.com/user-attachments/assets/3f9d4b85-09fd-41b5-829a-d4c15bbc8c5a" />

## 5. Добавление ReaComp

После добавления ReaGate необходимо добавить компрессор.

1. Нажмите зелёную кнопку **«+»**.

2. Выберите **Plugins → VST plugin**.

3. Нажмите на значок голубой папки.

4. Найдите файл `reacomp-standalone.dll`.

5. Выберите его и нажмите **«Открыть»**.

6. Откройте добавленный плагин ReaComp.

### Рекомендуемые настройки ReaComp

Установите следующие параметры:

| Параметр | Значение |
|:---|:---:|
| Pre-comp | `0 ms` |
| Attack | `10.0 ms` |
| Release | `100 ms` |
| Classic attack | `Включено` |
| Auto release | `Выключено` |
| Ratio | `3.0 : 1` |
| Knee size | `5.0 dB` |
| Lowpass | `20000 Hz` |
| Highpass | `80 Hz` |
| RMS size | `5.0 ms` |
| Threshold | `-20.0 dB` |
| Wet | `+10.0 dB` |

**Визуальный пример настроек:**

<img width="518" height="407" alt="7  ReaComp" src="https://github.com/user-attachments/assets/d028e497-abba-4165-bced-b3aca886e26e" />

> [!WARNING]
> Значение Wet `+10.0 dB` увеличивает уровень обработанного сигнала. Следите за индикатором выходного уровня и при необходимости уменьшите усиление, чтобы избежать перегрузки и клиппинга.

# 📌 Правильный порядок VST-плагинов

После добавления обоих плагинов обязательно проверьте их расположение в конфигурации.

Правильная последовательность обработки выглядит следующим образом:

```text
┌─────────────────────────┐
│         ReaGate         │
│      Шумоподавление     │
└─────────────────────────┘
             │
             ▼
┌─────────────────────────┐
│         ReaComp         │
│        Компрессор       │
└─────────────────────────┘
```

> [!IMPORTANT]
> Порядок расположения плагинов имеет значение! **ReaGate должен находиться выше ReaComp**, поскольку сначала необходимо обработать сигнал шумовым гейтом, а затем передать его компрессору.

# ⚠️ Важная информация

> [!CAUTION]
> Приведённые настройки являются примером конфигурации и не гарантируют одинаковый результат на всех микрофонах.
>
> Каждый микрофон имеет собственные характеристики, чувствительность и особенности звучания. Поэтому некоторые параметры могут потребовать индивидуальной корректировки.

> [!TIP]
> После завершения настройки проверьте звучание микрофона в приложении, которым вы обычно пользуетесь. Обратите внимание на громкость голоса, разборчивость речи, фоновый шум и отсутствие перегрузки.
